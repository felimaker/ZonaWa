// Recibe la carga útil del mensaje
const payload = await req.json();

if (payload.event === "message.upsert") {
  const phone = payload.data.key.remoteJid;
  const text = payload.data.message.conversation;
  
  // 1. Comprueba si es una intervención manual
  if (payload.data.key.fromMe) {
    await handleManualMessage(phone, text);
    return Response.json({ status: "paused" });
  }

  // 2. Ejecuta inferencia de IA
  const response = await generateAgentReply(phone, text);
  await sendWhatsappMessage(phone, response);
  
  return Response.json({ status: "200 OK" });
}

Preguntas Frecuentes

Solo debes ingresar el nombre del número de conexión en el panel de ZonaWa y el sistema generará un código QR único. Escanéalo desde tu dispositivo móvil a través de la sección "Dispositivos vinculados" en WhatsApp y la conexión quedará establecida.
Cuando un agente humano interviene en la conversación (ya sea desde el panel de ZonaWa o directamente desde el celular físico), el bot de IA se pausa para no interferir en el diálogo del operador. Puedes activar la continuación automática para que la IA retome el control en cuanto el cliente vuelva a escribir después de tu respuesta.
Sí. En ZonaWa puedes crear múltiples Estilos de IA independientes. Cada estilo puede tener su propio prompt de comportamiento, reglas de negocio específicas y estar vinculado a un proveedor de IA diferente (por ejemplo, OpenAI para un bot de ventas y Anthropic Claude para soporte de alta complejidad).
